# =====================================================================
#  RECEITA DO PRESET VOCAL "GELA"  (lilgiela33 / emo trap BR)  -  FL Studio
#  ---------------------------------------------------------------
#  Este .txt E o preset. O fl_chain_tool.py le cada linha e gira os knobs
#  na sua frente, batendo o valor que aparece escrito no plugin.
#
#  COMO USAR (com a track certa selecionada no mixer):
#     lead()        -> track do vocal (12)
#     dobras()      -> track das dobras (13)
#     adlibs()      -> track dos adlibs (14)
#     reverbfx()    -> track do GELA REVERB (16)
#     delayfx()     -> track do GELA DELAY (17)
#     apply_recipe()-> aplica TODOS os blocos presentes na track atual
#     xxx(dry_run=True) -> so confere, nao grava nada
#
#  FORMATO:  T|plugin|parametro|valor
#     - "valor" e escrito igual ao que aparece no knob: "-18.0 dB", "8.0:1",
#       "0.5 ms", "4x", "On", "Off", "Comp". Sem aspas.
#     - "~" separa nomes alternativos (o FL renomeia coisas entre versoes).
#     - "G|NOME" abre um bloco/bloco de grupo. Linhas valem para o grupo atual.
#     - "#" no inicio da linha = comentario.
#
#  SE UMA LINHA FALHAR: o script imprime "[!!]" com os NOMES REAIS daquele
#  plugin. Rode  params(<slot>)  e corrija o nome nessa linha. Nada de chute:
#  ele so grava um knob quando consegue CONFIRMAR que o texto dele virou o alvo.
# =====================================================================
